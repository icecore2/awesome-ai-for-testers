# Instructions for Unit Test Generation

## Getting Started
1. Install AI-powered IDE plugin (GitHub Copilot, Tabnine, etc.)
2. Open your source code file
3. Create a test file in your test directory
4. Start writing test function names and let AI suggest implementations

## Best Practices
- Write descriptive test names
- Use AI to generate edge cases
- Review and validate generated tests
- Ensure proper assertions are in place
